## Le portefeuille Sehelli
- Le solde et les dernières opérations sont visibles dans l'écran **Portefeuille** ; Sahla peut les consulter avec l'outil mon_portefeuille.
- Recharger : Portefeuille > **Recharger**, choisir le montant et le moyen de recharge. Sahla peut ouvrir l'écran recharger_portefeuille ; l'utilisateur confirme lui-même.

## Paiement refusé
Causes fréquentes : solde insuffisant, réseau instable, mauvais code saisi dans l'application de paiement. Conseiller de vérifier le solde, de réessayer avec une bonne connexion ou de choisir un autre moyen de paiement. Si l'argent a été débité sans que la commande soit validée : ticket support (catégorie paiement) avec la date, le montant et le moyen de paiement.

## Sécurité des paiements
Sehelli ne demande jamais un code PIN, un code reçu par SMS ou un mot de passe, ni par téléphone, ni par message, ni dans le chat. Toute personne qui le demande en se présentant comme Sehelli est un fraudeur : ne rien transmettre et signaler le cas au support (ticket catégorie securite).
